# Aerial Fishing Improvements

Adds configurable audio and visual effects when you receive Molch Pearls while Aerial Fishing.

![Demonstration](https://raw.githubusercontent.com/SchwingCoder/Aerial-Fishing-Improvements/main/images/aerial-fishing-improvements.gif)

# Features

When you pick up a pearl, this plugin will:

* **Play a sound effect.** (Configurable type and volume, or toggle it off)
* **Display a visual "+1" overlay.** (Configurable font, size, color, and animation)



(Test the sound effect and visual notification in the Developer settings.)
