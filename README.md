# Aerial Fishing Improvements

A RuneLite plugin that adds configurable notifications when you receive Molch Pearls while Aerial Fishing.

## Features

- Choose from four pearl pickup sounds: Pluck, Ding, Tick, and Chime
- Adjust the notification volume or disable sound
- Show an optional floating pearl notification with configurable font, size, color, and animation
- Preview the notification and sound from the Developer settings

Enable the plugin and configure its Audio and Visual options in RuneLite's plugin settings.
